    Code

    Wer den Einladungslink hat, kommt in eure Liste. Falls er in falsche Hände geraten ist oder jemand nicht mehr mitmachen soll: neuen Code erzeugen. Alle Daten ziehen mit um, alte Links funktionieren danach nicht mehr.

    Einfacher Modus: nur Eintragen, Abhaken, Fotos und ansehen, was an Ausgaben offen ist. Bearbeiten von Läden, Bons erfassen, Löschen und Verlauf sind ausgeblendet, damit nichts aus Versehen verloren geht. Gilt nur auf diesem Handy.
